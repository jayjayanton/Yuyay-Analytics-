# Yuyay Analytics

International sustainability, environmental evaluation, and geospatial analytics consultancy website.

## Preview
Open `index.html` locally or enable GitHub Pages from **Settings → Pages → Deploy from a branch → main / root**.

## Features
- Responsive landing page
- English/Spanish language toggle for principal headings and navigation (remaining content translation in progress)
- Filterable, CV-grounded historical project portfolio
- Environmental evaluation, sustainability and geospatial analytics services
- Team profiles
